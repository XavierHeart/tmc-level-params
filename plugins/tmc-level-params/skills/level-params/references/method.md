# 生成方法与口径

本文说明难度档位怎么从竞品数据学出来、每档参数怎么生成，以及统计口径和限制。

## 难度档位

竞品主线 2998 关自带难度标签：Normal 2399 关、Hard 334 关、ExHard 265 关。这三档在参数上重叠很大，直接按标签分档，Hard 和 ExHard 的参数很难拉开。所以先从标签里学出一个难度分，再按难度分重新切成 5 档。

1. **特征**：每关取 6 个参数，生成的参数也能算出同样的 6 个值。

   | 特征 | 计算 |
   |---|---|
   | 物件总数 | ln(T) |
   | 物件种类数 | U |
   | 目标种类数 | 目标有几种 |
   | 时长 | 秒 |
   | 叠放占比 | 叠在上层的物件数 ÷ T |
   | 有运动载具 | 有为 1，没有为 0 |

   目标总数没有用：竞品里只有约 40% 的目标数量能对上物件，其余要靠估计。

2. **模型**：逻辑回归，预测一关被竞品标成 Hard 或 ExHard 的概率。Normal 和 Hard/ExHard 的关数差很多，训练时按类别加权，两边同样重要。特征先标准化，再加 L2 正则。只用 Python 标准库，结果是确定的。
3. **难度分**：模型输出的对数几率。分越高，越像竞品的 Hard/ExHard。
4. **切档**：按难度分从低到高排序全部 2998 关，在 20%、40%、60%、80% 分位处切开，得到 5 档，每档约 600 关。
5. **检验**：5 折交叉验证。具体数值（AUC、各档的标签构成、特征权重）在 `model.json` 的 `tiers` 里，也写在生成结果的 `tier_model` 里。

## 每档参数的生成

每档的样本池是落在这一档的竞品关卡（约 600 关）。

| 步骤 | 做法 |
|---|---|
| 联合形态 | 按这一档里可完整分类关卡的形态分布抽样 |
| T/U | 从池中取一对真实 T/U；T 变化 ±0/3/6 后取 3 的倍数，U 变化 ±0/1 |
| 四类拆分 | 取一个同形态（优先同档）的真实样本，按它的种类比例和数量比例整体拆分 |
| 目标 | 种类数和单个目标数量从池中取；目标种类的数量 = 该种类全部数量 |
| 叠放 | 按池的叠放率开关；取池中一个真实关卡的叠放结构，套数四舍五入到 3 的倍数 |
| 运动载具 | 按池的运动率开关；开启时只用含载具的拆分样本 |
| 时长 | 从池中取 |
| 难度分 | 用同一个模型给生成的参数打分，必须落在这一档的分数区间内 |
| 验算 | 种类/数量加总、3 倍数、U≤T/3、目标明细、叠放套数与容量、运动前提、难度分在档内、经验范围。不通过就重抽这一档（最多 200 次） |

**同一主题的 5 档用同一套占位名**。每类都从 1 开始编号，例如某档有 5 种建筑，就用建筑1–建筑5。素材清单取每类在 5 档中的最大种类数，美术按清单画一次，5 档都够用。

**主题名只用作随机种子**，不影响参数的统计来源。同一主题名得到完全相同的结果。

整体验算：5 档齐全、每档验算通过、难度分逐档升高、没有完全相同的两档、每档的物件都在素材清单内。

## 口径与限制

- **T 含装饰物**。T 是一关的全部摆放行，和规则表的统计一致。`nc_`、`robot_` 等装饰物（每关数量通常不是 3 的倍数）也计入 T。生成时 T 全部分到四类里。
- **形态 F1–F5 是重新聚类的结果**，和规则表里的 F1–F5 不一一对应。只有 508 关能完整分类，各档的形态分布来自这些关卡。
- **目标数量**：只有约 40% 的目标名能对上已识别物件；生成时从这一档已知的目标数量中抽取。
- **叠放"层"** = 底座 + 上层物件的件数（2 层 = 1+1，3 层 = 1+2）。数据只记录嵌套顺序，没有区分"竖着叠"和"一个底座上放两个"。物件数量不够放下某个组合时会丢弃它，丢弃数记录在 `basis.stack_dropped`。
- **难度分只看参数**。摆放密度、遮挡、路径要布局后才能测量，没有进入难度分。
- **竞品的标签本身**：难度分学的是"竞品怎么标"，不是玩家实际觉得有多难。
