# 生成方法与口径

本文说明生成器每一步怎么做、数据从哪里来，以及统计口径和限制。

## 生成步骤

| 步骤 | 做法 | 数据依据 |
|---|---|---|
| 批次校验 | Normal+Hard+ExHard 必须等于区间关数，否则报错退出 | — |
| 难度位置 | 特殊关分层均匀散布；ExHard 不相邻（硬）；ExHard 后优先 Normal（软） | 规则表 |
| 关段样本池 | 官方顺序中同难度、关卡号相近的真实关卡，窗口从 ±25 开始加倍，直到至少 8 关 | `mainline_official_order.csv` |
| 联合形态 | 按难度 × 形态分布抽样；同形态连续不超过 3 关 | 508 个可完整分类关卡聚类为 F1–F5 |
| T/U | 从池中取一对真实 T/U；T 变化 ±0/3/6 后取 3 的倍数，U 变化 ±0/1 | 池 |
| 四类拆分 | 取一个同形态（优先同难度）真实样本，按它的种类比例和数量比例整体拆分 | 同形态样本 |
| 目标 | 种类数和单个目标数量从池中取；目标种类的数量 = 该种类全部数量 | `stageGroupIds` + 摆放数 |
| 叠放 | 按池的叠放率开关；取一个真实关卡的叠放结构，套数四舍五入到 3 的倍数 | `isNested` |
| 运动载具 | 按池的运动率开关；开启时只用含载具的拆分样本 | `hasWaypoint` |
| 时长 | 从池中取 | `Duration` |
| 验算 | 单关：种类/数量加总、3 倍数、U≤T/3、目标明细、叠放套数与容量、运动前提、经验范围。失败只重生该关（最多 200 次） | — |
| 批次验收 | 关数、三类数量、无相邻 ExHard、无完全重复行、同形态连续上限 | — |

## 口径与限制

- **T 含装饰物**。T 是一关的全部摆放行，和规则表的统计一致。`nc_`、`robot_` 等装饰物（每关数量通常不是 3 的倍数）也计入 T。生成时 T 全部分到四类里。
- **形态 F1–F5 是重新聚类的结果**，和规则表里的 F1–F5 不一一对应。可完整分类的 508 关中，大多数在 1000 关以后；早期关卡的四类比例借用这些关卡，T/U 仍然取自目标关段。
- **目标数量**：只有约 40% 的目标名能对上已识别物件；对不上时用同关段（不足 10 个时用同难度全体）的已知数量分布。
- **叠放"层"** = 底座 + 上层物件的件数（2 层 = 1+1，3 层 = 1+2）。数据只记录嵌套顺序，没有区分"竖着叠"和"一个底座上放两个"。物件数量不够放下某个组合时会丢弃它，丢弃数记录在 `basis.stack_dropped`。
- **难度位置是规则排位**，不是从竞品顺序学来的。
- Stage 1 参数只是难度先验。密度、遮挡、路径要布局后才能测量。
