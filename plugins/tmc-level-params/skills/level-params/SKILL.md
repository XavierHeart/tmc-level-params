# 关卡难度参数生成

本技能给策划用。策划输入一个主题名，输出这个主题在 5 个难度档位上各一组参数，以及 5 档共用的素材清单。物件用占位名（建筑1、道具3）；关卡生产时再把占位名换成这个主题的具体物件。

分工：

- **harness**（`scripts/level-params-harness`）负责生成和验算。所有数字都由它算，agent 不估、不改。
- **agent** 负责向策划要主题名、运行各步，并汇报结果。

难度档位是从竞品数据学出来的：用竞品自己的 Hard/ExHard 标签训练一个难度分，再按难度分把竞品关卡等分成 5 档，第 1 档最简单。每档的参数从落在这一档的竞品关卡里抽取，生成后再用同一个难度分检查，必须落在这一档。方法和口径见 [references/method.md](references/method.md)。

## 输入

只有一项：**主题名**（必填）。缺少时只问这一项。主题名只用作随机种子，同一主题名得到完全相同的结果；它不影响参数取自哪些竞品关卡。

## 流程

`$SKILL_DIR` 是本 SKILL.md 所在目录，`H="$SKILL_DIR/scripts/level-params-harness"`。运行目录缺省用当前工作目录下的 `level-params-<主题名>/`。

1. 建立运行目录：`"$H" init --run <运行目录> --theme <主题名>`。
2. 生成：`"$H" generate --run <运行目录>`。它为 5 档各生成一组参数、逐档和整体验算，写出 `level-params.json`、`.csv`、`.xlsx`。返回 1 表示验算失败，把失败项告诉策划，不说成通过。
3. 策划问到某一档时：`"$H" tier --run <运行目录> --tier <1-5>`，显示这一档的参数、依据（取自哪个竞品关卡）和验算结果。
4. 向策划汇报：
   - 三个文件的路径；
   - 每档的难度分、物件总数、种类数、目标种类数、是否叠放、是否运动、时长（`generate` 的输出里有）；
   - 素材清单：四类各几种、合计几种；
   - 验算结果。

   不在对话里贴整张参数表，策划看 xlsx。

其他命令：`check`（复查一份 level-params.json，策划手改过文件后用它）、`status`（当前状态）、`note`（记录决定）、`journal`（查看操作记录）。

## 输出内容

`level-params.json` 的结构：

| 字段 | 含义 |
|---|---|
| `theme`、`input` | 主题名、随机种子 |
| `tier_model` | 难度分模型：特征、权重、分档切点、交叉验证结果 |
| `tiers` | 5 组参数，每档一组（见下表） |
| `assets` | 素材清单：四类各几种、占位名列表、每档用到哪些 |
| `checks` | 整体验算 |
| `model_sha256` | 所用竞品统计数据的指纹 |

每档参数：

| 字段 | 含义 |
|---|---|
| `tier`、`score` | 档位（1 最简单，5 最难）；难度分 |
| `form`、`form_description` | 联合形态（竞品关卡聚类出的 F1–F5）和说明 |
| `T`、`U` | 物件总数（含装饰物，3 的倍数）、物件种类数 |
| `categories` | 建筑、道具、载具、角色各几种、共几个 |
| `per_kind` | 每种物件的数量（占位名，每种是 3 的倍数） |
| `targets` | 目标：哪几种、每种几个；目标数量等于这种物件在关卡里的全部数量 |
| `stacking` | 是否叠放、几层、哪几种物件叠在一起、各几套 |
| `motion` | 是否有运动载具 |
| `duration_s` | 时长（秒） |
| `basis`、`variation` | 依据：T/U、四类拆分、叠放结构分别取自哪个竞品关卡，以及 T/U 的变化量 |
| `checks` | 这一档的验算结果 |

xlsx 有三个 sheet：各档参数、素材清单、验算。xlsx 需要 `xlsxwriter`；没有安装时只跳过 xlsx，并提示 `pip install xlsxwriter`。

## 更新竞品数据

竞品数据更新后重新学习一次，生成新的 `model.json`（包括难度档位）：

```bash
python3 "$SKILL_DIR/scripts/learn.py" --data "<tmc资源包/数据>"
```

`model.json` 变了以后，同一主题名的结果也会变。`run.json` 和参数文件里都记录了 `model_sha256`。

## 范围和限制

- 只生成参数，不生成图片，不摆放关卡。
- 难度分学的是竞品怎么标难度，不是玩家实际觉得有多难；摆放密度、遮挡、路径没有进入难度分。
- 物件总数包含装饰物，和规则表的统计一致。
