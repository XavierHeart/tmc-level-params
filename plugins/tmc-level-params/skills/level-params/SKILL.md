# 关卡难度参数生成

本技能给策划用。输入一段关卡区间和三类难度的关数，输出这一段每一关的难度参数。物件用占位名（建筑1、道具3），不绑定主题；关卡生产时再把占位名换成具体主题的物件。

所有统计数值来自 `scripts/model.json`（由竞品主线数据学习得到），规则来自《关卡参数生成规则.xlsx》（统一生成规则）。每一步的做法和口径见 [references/method.md](references/method.md)。

## 需要策划给出的输入

| 输入 | 必填 | 说明 |
|---|---|---|
| 关卡区间 | 是 | 起止关卡号，例如 101–150 |
| Normal / Hard / ExHard 关数 | 是 | 三者之和必须等于区间关数 |
| 随机种子 | 否 | 缺省时由输入派生；同一输入和种子得到完全相同的结果 |
| 叠放率、运动率 | 否 | 覆盖关段的默认比例（0–1），对应规则表的"机制偏好" |

缺少必填项时只问缺的那一项，不猜。三类关数之和不等于区间关数时，把差值告诉策划，请策划改。

## 执行

`$SKILL_DIR` 是本 SKILL.md 所在目录。

1. 生成：

   ```bash
   python3 "$SKILL_DIR/scripts/generate.py" --start <起> --end <止> \
       --normal <N> --hard <H> --exhard <E> [--seed <种子>] \
       [--stack-rate <0-1>] [--motion-rate <0-1>] --out <输出目录>
   ```

   输出目录缺省用当前工作目录下的 `level-params-<起>-<止>/`。返回 0 表示批次验收全部通过；返回 1 表示有批次检查失败；返回 2 表示输入错误，把错误原文告诉策划。

2. 复查：

   ```bash
   python3 "$SKILL_DIR/scripts/generate.py" check --params <输出目录>/level-params.json
   ```

   输出 `ok` 才算通过。策划手改过 json 后也用这条命令复查。

3. 回复策划：
   - 三个文件的路径；
   - 每类难度的关数、物件总数和种类数的范围（取自 json 的 `distribution`）、叠放关数、运动载具关数；
   - 批次验收结果；有失败项时逐条列出，不说成通过。

   不在对话里贴整张参数表，策划看 xlsx。

## 可视化网页

策划要看曲线、对比竞品或重抽某一关时，在后台启动：

```bash
python3 "$SKILL_DIR/scripts/viewer.py" --port 8770 --out-root <导出目录>
```

然后把 `http://127.0.0.1:8770` 告诉策划。端口被占用时换一个端口。网页只监听本机。

网页功能：填写输入后生成；8 项压力的分项曲线和可调权重的综合曲线；竞品同编号关卡的曲线叠加；波动指标（σ、相邻关平均跳变、难度均分）；单关详情和"重抽此关"；导出 xlsx。

## 输出文件

| 文件 | 内容 |
|---|---|
| `level-params.json` | 完整结果：每关参数、依据（取自哪个竞品关卡）、单关检查、批次检查、输入、`model.json` 的 sha256。交给关卡生产的就是这个文件 |
| `level-params.csv` | 每关一行，中文列名，方便表格软件打开 |
| `level-params.xlsx` | 三个 sheet：试生成参数、批次验收、输入。需要 `xlsxwriter`；没有安装时只跳过这个文件，并提示 `pip install xlsxwriter` |

## 更新竞品数据

竞品数据更新后重新学习一次，生成新的 `model.json`：

```bash
python3 "$SKILL_DIR/scripts/learn.py" --data "<tmc资源包/数据>"
```

`model.json` 变了以后，同一输入和种子的结果也会变。json 里记录了 `model_sha256`，可以用来区分。

## 范围和限制

- 只生成参数，不生成图片，不摆放关卡，不判断主题。
- 难度位置按规则排位，不是从竞品顺序学来的。
- 参数只是难度的事前估计。摆放密度、遮挡、路径要在关卡摆放后才能测量。
- 物件总数包含装饰物，和规则表的统计一致。
